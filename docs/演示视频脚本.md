# 工友安全守护Agent — 演示视频脚本

> **目标时长**：≤2分钟（120秒）
> **拍摄方式**：屏幕录制 + 画外音
> **推荐工具**：OBS Studio（录屏）+ 剪映（剪辑）+ 手机录音（画外音）

---

## 视频结构总览

| 段落 | 时长 | 内容 | 一句话重点 |
|------|------|------|-----------|
| ① 开场 | 10秒 | 痛点+产品定位 | 一个对话框，管五件事 |

## 🎬 分镜脚本

### 镜头① 开场（10秒）

**画面**：
- 0:00-0:05：标题页"工友安全守护Agent"，工地照片背景
- 0:05-0:10：App首页功能卡片全貌（含Agent对话入口）

**画外音**：
> 建筑工友每天面对几十本安全规范，但没人能随身带着翻。这个AI安全助手，把它们装进了口袋。而且工友不用记五个功能——一个对话框，说人话就行。

---

### 镜头② Agent统一入口（20秒）【技术创新亮点】

**画面**：录屏，进入"对话助手"页面

**操作**：
- 输入"帮架子工生成一份脚手架安全培训"，展示 `st.status`："📝 生成培训内容" 工具被自动调度（5秒）
- 输入"工友触电了怎么办？"，展示"🆘 应急指导"工具自动路由（5秒）
- 上传一张照片 + 输入"看看这张照片有什么隐患"，展示"📷 分析工地照片"工具（8秒）
- 底部叠加字幕："一句话 → 自动判断意图 → 调度工具"（2秒）

**画外音**：
> 这是整个作品的技术核心——单Agent统一入口。工友说一句大白话，Agent自己判断该调用哪个工具：查规范、生成培训，还是分析照片。背后是DeepSeek的Function Calling，把四个专业功能，变成了一个会听话的对话框。

---

### 镜头③ 安全知识问答（20秒）

**画面**：录屏，暖橙主题，进入安全问答页面

**操作**：
- 输入"高处作业安全带应该怎么正确使用？"（3秒）
- 等待时展示 `st.status` 展开：检索知识库→找到3条规范→DeepSeek生成回答（3秒）
- 展示分点回答 + 底部标注"JGJ80-2016"（5秒）
- 点击示例问题"脚手架剪刀撑有什么要求？"，秒级回复（5秒）
- 快速切换三套主题：暖橙→浅色→深色（4秒）

**画外音**：
> 问一句大白话，Agent就从六份安全规范里检索条文，用通俗语言回答，还标出处。找不到的，它会诚实告诉你，绝不瞎编。三套配色，白天浅色、晚上深色，工友自己切。

---

### 镜头④ 工地隐患识别（20秒）

**画面**：进入隐患识别页面

**操作**：
- 上传一张脚手架照片，补充描述"三楼脚手架转角"（4秒）
- 点击分析，`st.status` 展开：编码图片→Qwen-VL逐项检查7大类安全问题（3秒）
- 展示结构化报告：🔴高风险"防护栏杆缺失"自动展开→整改建议→"立即"时限（7秒）
- 滚动展示🟡中风险、🟢低风险、✅符合规范的地方（4秒）
- 强调拍照模式："拍一张分析一张，不用点任何按钮"（2秒）

**画外音**：
> 工友发现脚手架不对劲，拍张照片。Agent逐项查七大类安全事项——从安全帽到基坑边坡。它不仅说哪里有问题，还说怎么改、什么时候改完，高风险自动标红。现场快速巡检，用拍照模式，拍一张分析一张。

---

### 镜头⑤ 安全培训助手（15秒）

**画面**：进入培训助手页面

**操作**：
- 快速选择：架子工 → 脚手架搭设安全 → 基础难度（3秒）
- 点击生成，展示 `st.status`：检索规范→生成大纲→写内容→出测验（4秒）
- 展示大纲列表 + 展开第一个章节的详细内容（4秒）
- 滚到测验题，点对一题 ✅、点错一题 ❌ 看纠错反馈（4秒）

**画外音**：
> 安全员最头疼的——找规范、写PPT、出考题。现在三个参数，40秒出一套完整培训包：大纲、讲解、测验。难度调到班组长，内容自动加深。

---

### 镜头⑥ 应急处理指导（20秒）

**画面**：进入应急指导页面

**操作**：
- 展示14类紧急类型按钮网格，点击红色的"触电"（3秒）
- 输入"工友碰到裸露电线，倒地了"，人数1，点击生成（3秒）
- 展示指导结果：⚡"立即切断电源"→分步操作→🚫"严禁用手直接拉触电者"→🚑何时打120（7秒）
- 滚到紧急上报区：自动生成的格式化报告（3秒）
- 手机端展示 tel:120 直接拨号（可用手机录一段）（4秒）

**画外音**：
> 紧急情况，工友可能慌了。Agent第一步就告诉你现在最该做的一件事，然后分步讲做什么、怎么做、为什么、禁止什么。最关键的是——它不止告诉你，还帮你做：自动生成报告，一键上报安全员，手机上直接拨120。黄金三分钟，Agent帮你抢。

---

## 🛠️ 制作指南

### 准备工作

| 材料 | 用途 |
|------|------|
| 脚手架/工地照片1-2张 | 镜头④隐患识别演示 |
| 标题封面（PPT/Canva） | 镜头①开场 |
| 架构图1张（PPT/Canva，三合一） | 镜头⑦收尾 |
| 收尾画面 | 镜头⑦ |

### 录制步骤

```
1. OBS录制Streamlit全流程操作
   → 每个模块单独录一段，方便重录翻车的模块
   → 分辨率1920×1080，30fps，隐藏浏览器书签栏和无关标签页
2. 手机录画外音
   → 安静环境，距离手机20-30cm，语速比日常慢20%
3. PPT/Canva做封面+架构图（共2张）
4. 剪映剪辑：
   → 先铺画面轨道
   → 叠画外音，逐段匹配时长
   → 加字幕（剪映自动识别+手动校正）
   → 调音量平衡
5. 导出：1080p MP4，码率控制在≤500MB
```

### 关键注意

| 要点 | 说明 |
|------|------|
| ⏱️ **严格控制时长** | 录完每段后看时间，超标就加速画面或压缩画外音 |
| 🖱️ **鼠标放慢** | 指向关键信息时停留1秒以上，不要来回晃 |
| 🎙️ **不要念课文** | 想象在给同学介绍项目，不是答辩。有热情但不夸张 |
| 🚫 **别用"然后"** | 用"接下来""再看""还有"替代 |
| 📱 **手机端展示** | 镜头⑥末尾用手机录一小段，展示tel:120拨号和移动端适配 |
| 🔗 **片尾加链接** | Demo链接 + GitHub链接，用字幕展示 |
