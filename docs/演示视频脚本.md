## 🎬 分镜脚本

### 镜头① 开场（30秒）

**画面**：
- 0:00-0:10：标题页"工友安全守护Agent — 建筑工地AI安全助手"，配一张建筑工地现场照片作为背景
- 0:10-0:30：三行痛点文字依次浮现，配合打字机音效

```
"安全规范几十本，工友记不住"
"安全员只有几个，不可能随叫随到"
"事故发生时，有多少人知道正确的急救步骤？"
```

**画外音**：
> 王师傅，45岁，架子工，初中文化。他凭经验干了15年，直到有一天脚手架扣件没拧紧。如果他当时能用手机问一句"扣件拧多紧才安全"，结果可能不一样。这是我开发工友安全守护Agent的原因——让每一位工友口袋里都有一个AI安全助手。接下来我带你看它能做什么。

**拍摄要点**：
- 封面页用PPT或Canva制作，大字号标题，干净背景
- 工地照片可从网上找无版权素材，建议用真实的脚手架/钢筋场景
- 画外音语气：平静、有故事感，不是念PPT

---

### 镜头② 安全知识问答（60秒）

**画面**：全屏录屏 Streamlit App，暖橙主题

**操作流程**：

*0:30-0:45 — 首页展示*
- 打开App，展示首页四宫格卡片 + 暖橙主题
- 鼠标依次划过四张卡片，展示hover动效
- 点击"安全知识问答"进入

*0:45-1:10 — 提问演示*
- 在输入框输入："高处作业安全带应该怎么正确使用？"
- 等待AI回复（2-3秒，正好是展示检索过程的自然停顿）
- 展示回复内容，鼠标指向规范出处"JGJ80-2016"

*1:10-1:20 — 快捷提问*
- 点击预制示例问题："脚手架剪刀撑有什么要求？"
- AI秒级回复
- 展示对话历史可以连续追问

*1:20-1:30 — 侧边栏展示*
- 打开侧边栏，展示三套主题切换（暖橙→浅色→深色快速切一遍再切回）
- 展示"📚 知识库就绪 — 18条规范"

**画外音**：
> 王师傅不用打字——他可以说大白话问问题。"安全带怎么系"，Agent就能从4份安全规范里找到相关条文，用通俗语言回答，还标注了规范出处。如果知识库里找不到，AI会诚实告诉你"这个我不太确定，建议问现场安全员"。旁边还有6个高频问题，点一下就能问。注意看右上角——这个App有三套配色，王师傅在太阳底下用浅色，晚上用深色，平时用暖色，他自己随便切。

**拍摄要点**：
- 录屏时浏览器窗口调到1920×1080
- 输入文字时故意慢一点，让观众看清你在输入什么
- 看完回复后停顿1-2秒再继续，给观众阅读时间
- 三套主题切换是视觉亮点，不要切太快

### 镜头③ 工地隐患识别（75秒）

**画面**：继续录屏，从首页进入隐患识别页面

**操作流程**：

*1:30-1:45 — 上传模式演示*
- 进入隐患识别页面
- 选择"📤 上传照片（可补充描述）"
- 上传一张准备好的工地照片（建议选一张脚手架场景的，有明显的安全亮点和隐患点）
- 在描述框输入："三楼脚手架转角，昨天刚搭好，注意看防护栏杆"
- 点击"🔍 开始隐患分析"

*1:45-2:15 — 分析结果展示*
- 等待3-4秒（AI分析中）
- 展示结构化分析报告：
  - 分析结论（一句话总结）
  - 🔴 高风险：防护栏杆缺失 → 整改建议（红色展开）
  - 🟡 中风险：材料堆放零乱 → 整改建议
  - 🟢 低风险：安全网有一处松动
  - ✅ 符合规范的地方（正向反馈）
- 鼠标滚轮滚动完整报告

*2:15-2:30 — 拍照模式演示*
- 选择"📸 快速拍照"
- 勾选"开启摄像头"开关
- 模拟拍照（或用另一张照片展示自动分析结果）
- 强调"拍完即自动分析，不需要额外操作"

*2:30-2:45 — 技术说明（画外音叠在屏幕上）*
- 屏幕显示Qwen-VL的7大检查要点清单

**画外音**：
> 王师傅发现脚手架有点不对劲，掏出手机拍张照片。Agent不只是说"有隐患"，它会告诉你：几处隐患、每处多严重、怎么整改、什么时候必须改完。这是因为它背后用的是Qwen-VL视觉大模型，能逐项检查7大类安全问题——从安全帽佩戴到基坑边坡，从电线破损到消防通道。而且它不仅说问题，也会告诉你哪儿做得好，这是对工人的正向反馈。如果你在巡检现场，用拍照模式，拍一张它就自动分析一张，不用点任何按钮——方便你在工地上边走边拍。

**拍摄要点**：
- 准备1-2张有真实隐患点的工地照片（脚手架缺护栏、电线乱拉、材料堆太高之类）
- 如果没有真实照片，可以用网图
- 分析结果出来时，鼠标在"高风险"的红色标记上停顿一下
- 滚动报告时速度放慢

### 镜头④ 安全培训助手（45秒）

**画面**：录屏，进入培训助手页面

**操作流程**：

*2:45-2:55 — 参数选择*
- 工种选择下拉框："架子工"
- 培训主题下拉框："脚手架搭设安全"
- 难度保持"基础"

*2:55-3:10 — 生成+展示*
- 点击"🎓 生成培训内容"
- 展示生成的培训大纲（5-8个知识点列表）
- 展开第一个章节"脚手架材料进场检查"，展示内容
- 鼠标指向"关键要点"和"常见错误"部分

*3:10-3:20 — 测验演示*
- 滚动到测验题部分
- 点击第1题答案B → 出现"✅ 正确！"
- 点击第2题答案C → 出现"❌ 不对。正确答案是A。解释：..."

*3:20-3:30 — 参数变化展示*
- 快速改难度为"班组长"，重新生成
- 展示内容明显更深入（大纲条数更多）

**画外音**：
> 安全员最头疼的就是准备培训材料——选主题、找规范、写PPT、出考题。现在说三个参数就够了：架子工、脚手架搭设、基础难度。40秒，一份完整的培训包就出来了：大纲、详细讲解、关键数据、常见错误做法，还附带5道测验题。工友当场就能答题，对错立刻知道。如果你培训的是班组长，把难度调到"班组长"，内容自动加深——规范条文引用更多、管理要求更细。

**拍摄要点**：
- 大纲出来后停顿1-2秒展示
- 测验环节故意答错一道，展示纠错反馈
- 难度切换是加分细节，不要跳过

### 镜头⑤ 应急处理指导（75秒）

**画面**：录屏，进入应急指导页面

**操作流程**：

*3:30-3:40 — 紧急类型选择*
- 展示14类紧急类型的按钮网格
- 鼠标指向红色的高风险按钮（触电、坍塌、火灾等）
- 点击"触电"

*3:40-3:55 — 填写信息+生成指导*
- 在"现场描述"输入："工友碰到裸露电线，倒地不起了"
- 涉及人数：1
- 点击"🆘 获取应急指导"
- 等待生成

*3:55-4:15 — 指导结果展示*
- ⚡ 第一件事：立即切断电源
- 📋 操作步骤（1-4步，每步有"做什么-怎么做-为什么-特别警告"）
- 🚫 绝对禁止：严禁用手直接拉触电者、禁止用湿物接触电线
- 🚑 何时打120：意识不清、心跳呼吸停止

*4:15-4:45 — 紧急上报功能（重点展示）*
- 滚动到紧急上报区域
- 展示自动生成的格式化紧急报告（事故类型、时间、地点、现场情况、已采取措施）
- 点击"🚨 一键上报" → 显示"✅ 已通知：现场安全员 | 项目经理 | 应急小组"
- 展开"📋 复制报告内容"，全选复制演示
- 鼠标指向"📞 拨打120"按钮——强调手机端点击直接拨号

**画外音**：
> 这是最重要的模块。当紧急情况发生，王师傅可能慌了，不知道先做什么。Agent不给长篇大论，第一步直接告诉你当前最该做的一件事：切断电源。然后分步指导，每一步都说清楚做什么、怎么做、为什么、特别注意什么——连绝对禁止事项都用红色醒目列出。但最关键的是下面这个——Agent不只是告诉你怎么做，它还帮你做。自动生成一份完整的紧急报告，包含事故类型、时间、现场情况。一键上报通知安全员和项目经理；点复制，直接粘贴到微信工作群；在手机上，点这个120按钮就直接拨号。从慌乱到有序，Agent帮王师傅抢到了最宝贵的黄金三分钟。

**拍摄要点**：
- 这是情感高潮段落，画外音语气从"紧迫"过渡到"安心"
- 紧急报告自动生成部分是核心亮点，给足画面时间
- 可以给"🚫 严禁用手直接拉触电者"一个红色特写（剪映里放大画面）
- 120按钮在手机端的tel:协议拨号是加分项，用画外音说清楚

### 镜头⑥ 技术架构（45秒）

**画面**：
- 切换到PPT/Canva制作的架构图（参见项目技术说明第二章）

**展示内容**（分三屏，每屏15秒）：

*4:45-5:00 第一屏 — 双模型架构*
```
用户输入 ─┬─ 文字 → TF-IDF检索 → DeepSeek → 回答
          └─ 照片 → 图片编码 → Qwen-VL → 报告
```

*5:00-5:15 第二屏 — 四模块总览*
```
安全问答 | 隐患识别 | 安全培训 | 应急指导
        （四个图标+一行描述）
```

*5:15-5:30 第三屏 — 安全守卫层*
```
8种异常场景全覆盖
超时降级 | 检索兜底 | 高风险审核 | 防重复提交 | 输入过滤
```

**画外音**：
> 技术上说三个亮点就够了。第一，双模型架构——DeepSeek管文字，Qwen-VL管图像。市面上大多数参赛作品只用一个模型，我们同时驾驭两个。第二，四个模块不是四个独立功能——它们共享同一套知识库、同一套安全守卫机制，是一个整体设计。第三，完整兜底——断网不会白屏、超时有提示、高风险有强制警告。8种异常场景都有退路。竞赛评审不是只看你演示的时候有多顺，也看你翻车的时候有多稳。

**拍摄要点**：
- 架构图用PPT做，不要太花哨，黑白/橙色配色，信息清晰
- 每屏停留时画外音说完后停顿1秒再切换
- 不需要动画，静态图+画外音更专业

## 🛠️ 制作实操

### 准备工作清单

| 材料 | 用途 | 状态 |
|------|------|------|
| 一张工地脚手架照片（有隐患点） | 镜头③上传演示 | 需要准备 |
| 一张工地全景照片（无明显隐患） | 镜头③拍照模式演示 | 可选 |
| 三张PPT架构图 | 镜头⑥技术展示 | 用PPT/Canva制作 |
| 开场封面 + 收尾封面 | 镜头①⑦ | 用PPT/Canva制作 |

### 制作步骤

```
第1步：用OBS录制Streamlit全流程操作（约10分钟素材）
        → 每个模块单独录一段，方便剪辑时调整顺序
第2步：用手机录制画外音（对着脚本念）
        → 选安静环境，距离手机20-30cm，语速比日常说话慢20%
第3步：用PPT/Canva制作封面图 + 架构图（共5张）
第4步：在剪映中按分镜脚本剪辑拼接
        → 先铺画面轨道，再叠画外音轨道
第5步：加字幕、调音量平衡、导出1080p MP4
```

### 录屏设置

- 分辨率：1920×1080
- 帧率：30fps
- 录制区域：浏览器窗口（Streamlit App）
- **务必隐藏**：浏览器书签栏、地址栏中的个人信息、无关标签页
- **务必关闭**：微信/QQ通知弹窗
- 录制前重启浏览器，清缓存，确保App加载速度正常

### 避坑清单

1. **不要说"然后"**——画外音里"然后"是最常见的口头禅，听着不专业。用"接下来""接下来看""再看"替代。
2. **画面不动时闭嘴**——如果屏幕上在展示一个报告，给观众3-4秒阅读时间，画外音跟着画面走。
3. **鼠标别乱晃**——录屏时鼠标移动要刻意放慢，指向关键信息时停留1秒以上。
4. **不要从头录到尾一次过**——每个模块单独录一段，剪辑时拼接。万一某个模块翻车可以单独重录。
5. **检查部署URL**——视频里如果要展示URL，确认Streamlit Cloud链接能正常打开。建议在视频末尾字幕加上Demo链接和GitHub链接。
6. **画外音不要像念课文**——想象你是在给同学介绍你的项目，不是在答辩。带一点热情，但不要夸张。
