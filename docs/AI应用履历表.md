## 四、AI协同方式总结

| 协同维度 | 具体体现 |
|---------|---------|
| **AI辅助开发** | 通过Claude进行代码编写、架构设计、Debug、部署配置。AI负责生成代码框架和处理重复性任务，我负责架构决策、质量把关和最终验收 |
| **AI作为产品能力** | DeepSeek和Qwen-VL是产品的核心引擎，不是锦上添花——去掉AI，产品无法工作 |
| **人机分工** | AI负责：知识检索、规范匹配、内容生成、格式转换；人负责：场景判断、最终决策、安全把关 |
| **AI可追溯** | 每条AI回答标注规范出处；检索无结果时诚实告知而非编造；高风险场景强制追加人工审核提示 |
| **异常兜底** | 13种异常场景均有降级策略——AI不可用时，系统不会崩溃，会给出离线建议或友好引导 |
