## 二、作品摘要（200字以内）

工友安全守护Agent是一款面向建筑工地一线工人的AI智能安全助手。产品将高处作业、临时用电、脚手架、个人防护装备4份核心安全规范构建为TF-IDF知识库，结合DeepSeek和Qwen-VL双大模型，实现四大功能：安全知识问答——工友用大白话提问，AI检索规范后通俗回答并标注出处；工地隐患识别——拍照上传，AI自动识别安全隐患并给出整改建议和规范引用；安全培训助手——选工种定主题，自动生成培训大纲、详细内容和配套测验；应急处理指导——覆盖14类事故的分步应急指令，带自动报告生成和一键拨120。产品基于Streamlit开发，部署在Streamlit Cloud上，手机浏览器即开即用。

## 三、AI技术应用说明

### 3.1 使用的AI技术

| 技术 | 应用说明 |
|------|----------|
| 大语言模型（LLM） | DeepSeek-V3（deepseek-chat）：承担安全问答、培训内容生成、应急指导生成等文本任务 |
| 视觉大模型（Vision LLM） | Qwen-VL（qwen-vl-max）：分析工地现场照片，识别7大类安全隐患并生成结构化报告 |
| 检索增强生成（RAG） | TF-IDF关键词检索 + 余弦相似度匹配（scikit-learn）：从建筑安全规范知识库中检索Top-3相关段落，作为LLM回答的事实依据 |
| Prompt Engineering | 5套定制System Prompt：通用安全助手人设、知识问答模板、视觉分析Schema、培训生成Schema、应急指导Schema。所有输出强制JSON结构化 |
| 异常处理与兜底 | 分层降级策略：检索无结果→纯LLM兜底；API超时→友好重试提示；高风险场景→自动追加人工审核警告；非安全问题→礼貌拒绝并引导 |

### 3.2 AI协同能力体现

**人机协同规划**：
- 系统负责：知识检索、规范匹配、内容生成、格式结构化
- 人类负责：场景判断（拍什么照片、选什么紧急类型）、最终决策（是否采纳整改建议、是否上报）
- AI建议 + 人工确认：每条回答标注规范来源供核实，高风险隐患强制追加审核提醒

**AI交互迭代逻辑**：
- 安全知识问答支持多轮对话，可连续追问深入
- 隐患识别支持"拍照即分析"和"上传+描述"双模式，适应不同使用习惯
- 应急指导提供14类事故按钮选择 + 现场描述自由输入，结构化交互降低误操作
- 培训助手支持工种×主题×难度三维组合，灵活适配不同培训需求

**AI纠偏管理**：
- RAG机制约束：回答基于检索到的规范原文，非凭空生成
- 检索无结果时诚实告知，标注"未在规范库中找到直接依据，以下内容仅供参考"
- 每条回答标注规范出处，知识可追溯
- 视觉分析要求JSON Schema输出，非结构化返回时有兜底展示
- System Prompt内置边界约束：不确定的内容明确说"建议咨询现场安全员"

## 四、场景创意说明

### 4.1 目标用户与痛点

**目标用户**：建筑工地一线施工工人（以"王师傅"为典型画像——45岁架子工，初中文化，会用微信发语音但不太会打字，凭经验干活，觉得"我干了这么多年都没出事"）

**核心痛点**：
1. **安全规范门槛高**：JGJ 80等行标术语密集，一线工人看不懂也接触不到
2. **安全员覆盖有限**：一个安全员管几百号工人，无法做到随时随地咨询
3. **事故时容易慌**：缺乏应急训练，事故发生时不知道第一步做什么、绝对不能做什么
4. **培训形式单一**：传统安全培训以"大会讲课"为主，缺乏针对性和互动性

### 4.2 创意亮点

**① 土木人做给土木人——场景驱动而非技术驱动**

参赛者本身是土木工程专业学生，对建筑施工现场的安全痛点有切身体会。产品设计从工友的真实需求出发，而非从技术能力出发——先想清楚"王师傅需要什么"，再决定"用什么技术实现"。

**② "大白话↔规范"双向翻译**

工友用日常语言提问→系统检索专业规范条文→LLM转化为通俗回答。这是在专业知识和普通人之间架一座翻译桥梁，而不是简单地把规范文档丢给工人自己看。

**③ 从"告诉你"到"帮你做"**

应急模块不只是告知操作步骤。它自动生成格式化紧急报告、提供一键复制（发微信/钉钉）、手机端一键拨120——在慌乱中帮工人完成关键动作，而不只是告诉他要做什么。

**④ 双模型协同覆盖文字+图像**

大多数参赛作品只用一个文本模型。本项目同时整合DeepSeek和Qwen-VL，覆盖"文字问答"和"图像巡检"两类核心安全场景，技术维度更完整。

### 4.3 落地可行性

- **零安装**：手机浏览器直接访问，不占存储空间
- **低成本运行**：DeepSeek API ¥1/百万tokens，单次问答约¥0.002；Qwen-VL单次分析约¥0.02
- **知识可维护**：TXT格式的规范文档，新增规范只需添加文件后运行`init_kb.py`
- **免费托管**：Streamlit Cloud免费Plan即可运行

## 六、自我评价

### 作品优势
1. **场景真实**：从土木专业视角出发，解决建筑行业真实安全痛点，非凭空想象
2. **覆盖面广**：四模块覆盖安全知识获取、现场巡检、培训准备、紧急处置全链路
3. **双模型创新**：文本+视觉双模型协同，单个作品展示两种AI能力的整合
4. **体验考虑周全**：从工友视角设计（大白话交互、手机访问、三套主题），非技术自嗨
5. **工程完整度高**：有兜底设计、有异常处理、有UI设计系统、有实际部署

### 不足之处
1. 知识库规模有限（4份规范），覆盖的安全场景还不够全面
2. 应急报告目前为模拟发送，未接入真实短信/钉钉通知API
3. 缺少用户反馈收集机制，无法根据实际使用情况优化回答质量
4. TF-IDF检索对长尾语义查询的召回精度不如向量检索

### 后续规划
- 短期：接入真实通知API，实现应急报告真实推送
- 中期：扩充知识库（深基坑、塔吊安拆、模板工程等），引入向量检索作为补充
- 长期：增加语音输入、构建企业级安全管理仪表盘
