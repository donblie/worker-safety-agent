**工友安全守护Agent | 独立开发**
*2026.07 — 2026.08*

## 写法二：AI/算法岗（侧重技术深度，约250字）

**工友安全守护Agent — 多模态RAG智能安全助手 | 独立开发**
*2026.07 — 2026.08*

- 独立完成从需求分析、系统设计到开发部署的全流程，面向建筑工地场景构建AI安全智能体
- **多模型协同**：设计DeepSeek-V3+Qwen-VL双模型架构，文本模型负责安全问答、培训生成、应急指导，视觉模型负责工地照片的7大类隐患识别（人员防护/高处作业/临时用电/机械设备/物料堆放/基坑边坡/消防安全），输出结构化JSON报告（隐患类型-风险等级-整改建议-整改时限）
- **RAG检索管线**：基于jieba分词+TF-IDF向量化+余弦相似度匹配，自建建筑安全规范知识库（500字滑动窗口切片、50字重叠保证语义连贯），Top-3召回后注入LLM上下文，回答附带规范出处，事实性错误显著降低
- **工程鲁棒性**：设计分层兜底架构——检索无结果降级为纯LLM模式并诚实告知、API超时自动重试+友好降级提示、高风险场景自动追加人工审核警告、非安全相关输入礼貌拒绝并引导——共8种异常路径覆盖
- **Prompt Engineering**：编写5套定制System Prompt（角色人设/问答/视觉分析/培训生成/应急指导），所有LLM输出强制JSON Schema约束，解析失败时有结构化兜底展示
- 使用Python+Streamlit实现全栈，Streamlit Cloud免费部署，手机端自适应，日均成本<¥0.1

**技术栈**：Python / Streamlit / DeepSeek API / Qwen-VL / TF-IDF / jieba / Prompt Engineering / RAG / Git

## 写法三：产品/综合岗（侧重场景洞察与产品思维，约200字）

**工友安全守护Agent | 产品设计与全栈开发**
*2026.07 — 2026.08*

- 从建筑工地一线工人的真实需求出发，独立完成产品规划、技术选型与全栈开发
- 核心洞察：安全规范"躺在文件柜里，不在工友口袋里"——45岁架子工看不懂规范术语、安全员管几百人忙不过来、事故发生时周边人不知道该做什么
- 产品策略：不做大而全的平台，聚焦四个高频刚需场景（随时问安全知识、拍照查隐患、按工种生成培训、紧急情况分步指导），通过"大白话↔规范"双向翻译降低使用门槛
- 技术落地：整合DeepSeek+Qwen-VL双模型，自建TF-IDF知识库实现带出处的规范问答；应急模块实现"指导→自动生成报告→一键上报→一键拨120"的完整闭环，而非仅停留在信息展示层
- UI设计三套可切换主题（暖橙/浅色/深色）适应工地多变光线环境，全局CSS覆盖所有Streamlit原生组件
- 全程使用Claude辅助编程，实践AI-native开发模式：从选题论证、架构评审、代码实现到文档撰写

**技术栈**：Python / Streamlit / LLM应用 / RAG / 产品设计 / AI辅助开发
