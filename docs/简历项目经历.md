## 写法一：通用版（适用大部分岗位，约200字）

**工友安全守护Agent | 独立开发**
*2026.07 — 2026.08*

- 面向建筑工地场景，独立设计并开发了一款基于双大模型的AI安全助手，覆盖安全知识问答、工地隐患拍照识别、培训自动生成、应急处理指导、Agent对话五大功能
- 采用DeepSeek-V3（文本）与Qwen-VL（视觉）双模型协同架构，一套系统同时支持自然语言问答和图像巡检两类核心场景。新增Function Calling单Agent统一入口，用户一句自然语言即可自动路由到正确工具

- 实现流式输出(SSE)、JSON Schema自动校验与字段补全、LRU缓存+TTL过期、结构化API日志等工程化实践
- 设计13种异常场景降级策略（超时/断网/错误输入/高风险审核/流式中断/Schema缺失等），确保极端情况下系统不崩溃
- 使用Python+Streamlit完成全栈开发，部署于Streamlit Cloud，手机浏览器即开即用
- 荣获第一届"海之子"杯AI智能体挑战计划[获奖情况待填]

## 写法二：AI/算法岗（侧重技术深度，约250字）

**工友安全守护Agent — 多模态RAG智能安全助手 | 独立开发**
*2026.07 — 2026.08*

- 独立完成从需求分析、系统设计到开发部署的全流程，面向建筑工地场景构建AI安全智能体
- **多模型协同**：设计DeepSeek-V3+Qwen-VL双模型架构，文本模型负责安全问答/培训生成/应急指导/Function Calling，视觉模型负责工地照片的7大类隐患识别，输出结构化JSON报告
- **RAG检索管线**：TF-IDF关键词检索（char ngram 1-2，零外部依赖），自建建筑安全规范知识库（500字滑动窗口切片、50字重叠），Top-3召回+相似度阈值过滤后注入LLM上下文，回答附带规范出处；预留BGE语义嵌入接口可无缝升级
- **Agent工具调度**：基于Function Calling实现单Agent统一入口，4个Tool（规范检索/照片分析/培训生成/应急指导）自动调度，用户一句自然语言即可路由到正确功能
- **工程鲁棒性**：设计分层兜底架构——流式输出+SSE、JSON Schema自动校验+字段补全、LRU缓存+TTL过期、13种异常路径覆盖（含流式中断/Schema缺失/知识库未就绪）
- **Prompt Engineering**：编写6套定制System Prompt（角色人设/问答/视觉/培训/应急/Agent），所有LLM输出JSON Schema约束+字段级校验
- 使用Python+Streamlit实现全栈，Streamlit Cloud免费部署，手机端自适应，日均成本<¥0.1

**技术栈**：Python / Streamlit / DeepSeek API / Qwen-VL / RAG / Function Calling / Prompt Engineering / Git

## 写法三：产品/综合岗（侧重场景洞察与产品思维，约200字）

**工友安全守护Agent | 产品设计与全栈开发**
*2026.07 — 2026.08*

- 从建筑工地一线工人的真实需求出发，独立完成产品规划、技术选型与全栈开发
- 核心洞察：安全规范"躺在文件柜里，不在工友口袋里"——45岁架子工看不懂规范术语、安全员管几百人忙不过来、事故发生时周边人不知道该做什么
- 产品策略：不做大而全的平台，聚焦五个高频刚需场景（Agent对话智能调度、随时问安全知识、拍照查隐患、按工种生成培训、紧急情况分步指导），通过"大白话↔规范"双向翻译降低使用门槛
- 技术落地：整合DeepSeek+Qwen-VL双模型，自建TF-IDF检索知识库实现带出处的规范问答；Agent Function Calling实现"一句话描述需求→自动路由工具"的智能体验；流式输出让长回答逐字呈现；应急模块实现"指导→报告→上报→拨120"完整闭环
- UI设计三套可切换主题（暖橙/浅色/深色）适应工地多变光线环境，全局CSS覆盖所有Streamlit原生组件
- 全程使用Claude辅助编程，实践AI-native开发模式：从选题论证、架构评审、代码实现、AI Engineer架构评估到文档撰写

**技术栈**：Python / Streamlit / LLM应用 / RAG / Agent / 产品设计 / AI辅助开发
